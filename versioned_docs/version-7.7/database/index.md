# Baza danych

Sekcja zawiera techniczny opis bazy danych SPUMA.

Dokumentacja obejmuje:

- [**Tabele**](/versioned_docs/version-7.7/database/Tables/index.md),
- [**Procedury**](/versioned_docs/version-7.7/database/Procedures/index.md),
- [**Funkcje**](/versioned_docs/version-7.7/database/Functions/index.md).

Każdy obszar został opisany w osobnej sekcji.

Część zaawansowanych funkcjonalności systemu SPUMA konfiguruje się za pomocą procedur i funkcji SQL.

:::warning
- Modyfikację procedur i funkcji należy zlecić osobom technicznym znającym SQL oraz strukturę bazy danych SPUMA.
- Zabronione jest bezpośrednie modyfikowanie danych w bazie za pomocą instrukcji `INSERT`, `UPDATE` i `DELETE`.
- Przy edycji procedur i funkcji zalecane jest dodawanie komentarzy opisujących zmiany wprowadzone względem standardowej funkcjonalności.
:::
