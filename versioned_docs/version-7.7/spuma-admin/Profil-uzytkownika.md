# Profil użytkownika

Menu **Profil użytkownika** zawiera podstawowe operacje związane z aktualnie zalogowanym użytkownikiem.

Dostępne opcje:

- **Pomoc** - Otwiera dokumentację SPUMA.

- **Sprawdź licencje** - Otwiera informacje o wykorzystaniu licencji.

- **Wyloguj** - Kończy bieżącą sesję użytkownika.

## Sprawdź licencje

Okno **Sprawdź licencje** prezentuje:

- liczbę dostępnych licencji,
- liczbę aktualnie zajętych licencji,
- listę sesji zajmujących licencje.

Dla każdej aktywnej sesji dostępne są informacje m.in. o użytkowniku, dacie logowania oraz ostatniej aktywności.

W prawym górnym rogu dostępne są dodatkowe operacje:

- **Odśwież** - Ponownie pobiera bieżący stan wykorzystania licencji.
- **Pobierz licencje** - Pobiera wykupione licencje z systemu licencyjnego. Funkcja jest używana przy pierwszym uruchomieniu licencji oraz po zwiększeniu ich liczby.

:::note
Licencje są generowane po stronie systemu licencyjnego. Po ich pierwszym pobraniu nie ma potrzeby ponownego używania opcji **Pobierz licencje**, chyba że liczba wykupionych licencji została zwiększona.
:::
