# Zakładka - Uprawnienia

Zakładka **Uprawnienia** służy do definiowania uprawnień dla dokumentów danej firmy.

Uprawnienia zdefiniowane na firmie są stosowane do wszystkich dokumentów przypisanych do tej firmy. Szczegółowy opis mechanizmu uprawnień znajduje się w sekcji [**Uprawnienia**](/versioned_docs/version-7.7/spuma-admin/uprawnienia.md).
