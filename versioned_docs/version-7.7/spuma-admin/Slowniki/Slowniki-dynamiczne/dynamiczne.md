# Słowniki dynamiczne

**Słowniki dynamiczne** pobierają wartości na podstawie zapytania SQL zdefiniowanego bezpośrednio w konfiguracji słownika.

Dane są pobierane w momencie użycia słownika, np. podczas otwierania listy wartości. Dzięki temu słownik zwraca aktualne dane ze źródła, ale wymaga dostępnego połączenia z bazą.

Zapytanie może korzystać z parametrów pobierających wartości z obiektu nadrzędnego.
