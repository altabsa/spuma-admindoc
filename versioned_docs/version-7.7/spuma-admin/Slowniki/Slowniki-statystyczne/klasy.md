# Zakładka - Klasy

Zakładka **Klasy** zawiera listę klas, w których używany jest dany słownik statyczny.

Lista jest uzupełniana automatycznie na podstawie konfiguracji atrybutów klas.

Z poziomu listy możesz przejść bezpośrednio do konfiguracji wybranej klasy.

:::note
Lista ma charakter informacyjny. Powiązania słownika z klasami nie są definiowane bezpośrednio w tej zakładce.
:::
