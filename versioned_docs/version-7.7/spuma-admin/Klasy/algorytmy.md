# Zakładka - Algorytmy

Zakładka **Algorytmy** zawiera listę algorytmów powiązanych z daną klasą.

Lista jest uzupełniana automatycznie na podstawie konfiguracji klasy i elementów, które odwołują się do algorytmów.

Z poziomu listy możesz przejść bezpośrednio do konfiguracji wybranego algorytmu.
