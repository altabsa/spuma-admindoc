# Zakładka - Uprawnienia

Zakładka **Uprawnienia** służy do definiowania uprawnień dla dokumentów danej klasy.

Uprawnienia zdefiniowane na klasie są stosowane do wszystkich dokumentów przypisanych do tej klasy. Szczegółowy opis mechanizmu uprawnień znajduje się w sekcji [**Uprawnienia**](/versioned_docs/version-7.7/spuma-admin/uprawnienia.md).
