# Zakładka - Użytkownicy

Zakładka **Użytkownicy** zawiera listę użytkowników przypisanych do grupy.

Z poziomu zakładki możesz:

- dodać użytkownika do grupy,
- usunąć użytkownika z grupy,
- przejść bezpośrednio do konfiguracji wybranego [użytkownika](/versioned_docs/version-7.7/spuma-admin/Uzytkownicy/Uzytkownicy/uzytkownicy.md).
