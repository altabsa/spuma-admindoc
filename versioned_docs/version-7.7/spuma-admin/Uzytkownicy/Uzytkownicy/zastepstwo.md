# Zakładka - Zastępstwo

Zakładka **Zastępstwo** służy do konfiguracji zastępstwa dla użytkownika.

Zastępstwo może zostać ustawione samodzielnie przez użytkownika w aplikacji W&#87;W lub przez administratora w aplikacji administracyjnej.

---

## Właściwości

- `Aktywne` - Włącza lub wyłącza zastępstwo.

- `Od/Do` - Data rozpoczęcia/zakończenia zastępstwa.

- `Zastępuje/Lub` - Użytkownik lub użytkownicy wskazani do realizacji zastępstwa.
