# SPUMA Initial Configuration Guide

## Document Purpose

The purpose of this guide is to perform the basic configuration of the SPUMA system after installation has been completed and the environment has been verified to work correctly.

The initial configuration includes:

- obtaining and activating the license,
- configuring the main system settings,
- configuring companies,
- defining users and groups,
- configuring document workflows,
- assigning permissions,
- configuring integrations with external systems.

The individual steps should be performed in an order that reflects the dependencies between the configured elements.
