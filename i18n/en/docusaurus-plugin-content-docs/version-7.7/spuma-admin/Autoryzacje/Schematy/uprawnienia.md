# Permissions Tab

The **Permissions** tab is used to define the permissions that apply to the selected authorization schema.

Permissions are divided into:

- **Header permissions** - apply to fields and operations at the document level,
- **Line permissions** - apply to fields and operations at the document line level.

A detailed description of the permissions mechanism is available in the [**Permissions**](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/uprawnienia.md) section.
