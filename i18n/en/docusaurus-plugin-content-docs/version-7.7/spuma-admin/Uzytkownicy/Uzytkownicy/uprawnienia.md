# Permissions Tab

The **Permissions** tab is used to define the user's access to companies.

---

## Properties

- `Company permissions` - Specifies the user's access scope to companies:
  - All - the user has access to all companies,
  - Selected only - the user has access only to the companies listed in the **Selected Companies** section.

---

## Selected Companies

The **Selected Companies** section is used when `Selected only` is selected.
