# During this period Tab

The **During this period** tab is used to configure substitution for the user.

Substitution can be configured by the user in the web application or by an administrator in the administration application.

---

## Properties

- `Active` - Enables or disables substitution.

- `From/To` - Substitution start/end date.

- `Replaces/Or` - User or users assigned to perform the substitution.
