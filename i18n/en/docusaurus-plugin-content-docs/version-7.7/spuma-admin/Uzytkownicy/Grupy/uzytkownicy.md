# Users Tab

The **Users** tab contains a list of users assigned to the group.

From this tab, you can:

- add a user to the group,
- remove a user from the group,
- navigate directly to the configuration of the selected [user](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/Uzytkownicy/Uzytkownicy/uzytkownicy.md).
