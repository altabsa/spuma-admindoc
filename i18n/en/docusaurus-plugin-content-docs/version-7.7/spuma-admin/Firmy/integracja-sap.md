# SAP Integration Tab

The **SAP Integration** tab contains the company's SAP connection settings and parameters used during data exchange.

---

## Properties

- `SL Address` - SAP Service Layer address.

- `User` - SAP user used for the connection.

- `Password` - SAP user password.

- `Generate new BP code (SQL SL)` - SQL query executed by Service Layer to generate a new Business Partner code.

- `Default item` - Default SAP item code.

- `Branch ID` - Branch identifier used in SAP.

- `Sales date field` - Technical name of the SAP field used to store the sales date.

- `E-document number field` - Technical name of the SAP field used to store the electronic document number.
