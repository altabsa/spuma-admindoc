# General Tab

The **General** tab contains basic global SPUMA settings related to e-mail, external services, KSeF, and selected interface parameters.

---

## Properties

- `SMTP address` - Address of the default SMTP server used to send e-mail messages.

- `SMTP user` - SMTP server user name.

- `SMTP port` - SMTP server port.

- `SMTP password` - SMTP server user password.

- `Pending report schedule` - Schedule for running the pending documents report. The value is stored as a `cron` expression. The schedule defines when the system generates and sends the report to users who have enabled receiving it.

  This setting is global for the entire SPUMA installation.

  Example schedule that runs the report every day at `08:00`:

  ```cron
  0 8 * * *
  ```

- `Session file` - Path to the session file on the server.

- `Client ID` - Unique SPUMA client identifier. The identifier is defined during implementation and is used, among other things, by the OCR service to identify the client configuration.

- `Remote address` - Address used in e-mail messages sent by SPUMA.

- `KSeF API` - Address of the KSeF API used for communication with the National e-Invoice System.

- `KSeF Render API` - Address of the service that generates a PDF preview from a KSeF XML document.

- `GPT ApiKey` - API key used for communication with the GPT service.

- `Print footer` - Text placed in the footer of printouts generated by SPUMA.

- `Supervisors` - User group that acts as the default supervisors for the entire SPUMA installation.

- `Rows per document list` - Number of rows displayed on the document list.
