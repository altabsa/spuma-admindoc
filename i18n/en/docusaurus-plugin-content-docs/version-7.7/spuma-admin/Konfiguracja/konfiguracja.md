# Configuration

The **Configuration** section contains global SPUMA settings.

The configuration is divided into the following tabs:

- [**General**](./ogolne),
- [**OCR**](./ocr),
- [**Automation**](./automatyzacja),
- [**Security**](./bezpieczenstwo),
- [**JS Functions**](./funkcje-js),
- [**Modules**](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/Konfiguracja/moduly/dataservise.md).

The settings in this section apply to the entire SPUMA installation and can affect, among other things, integrations with external services, OCR mechanisms, automation, and available system modules.
