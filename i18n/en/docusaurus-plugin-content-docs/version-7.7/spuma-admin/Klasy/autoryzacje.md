# Authorizations Tab

The **Authorizations** tab contains the settings for authorization [schemas](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/Autoryzacje/Schematy/schematy.md)/[processes](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/Autoryzacje/Procesy/procesy.md) available for documents of this class.

---

## Properties

- `Custom schema` - Allows the user to create a custom authorization schema and send the document through a workflow.

- `Schema is required` - Specifies whether a document must be assigned to an authorization schema.

- `Default schema` - Specifies the authorization schema assigned to documents of this class by default.

- `Available schemas` - Lists the authorization schemas/processes available for the class.
