# Triggers Tab

The **Triggers** tab is used to define buttons available for documents of this class in the web application.

Clicking a button triggers an event defined in the algorithms.

---

## Trigger Configuration

- `Name` - Trigger code. The name must be unique within the class and match the name of the algorithm that handles the trigger.

- `Label` - Text displayed on the button in the web application.

- `Description` - Trigger description displayed only in the administration application.

- `Linked to field/after` - Specifies where the trigger button is displayed:
  - `End` - the button is displayed at the end of the section,
  - selected field - the button is displayed after the selected field or column.

- `Link` - Links the trigger button to the selected field.
