# Permissions Tab

The **Permissions** tab is used to define permissions for entries in the selected correspondence log.

Permissions defined for a correspondence log are applied to all of its entries. A detailed description of the permissions mechanism is available in the [**Permissions**](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/uprawnienia.md) section.
