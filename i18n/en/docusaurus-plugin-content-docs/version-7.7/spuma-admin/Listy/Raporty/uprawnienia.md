# Permissions Tab

The **Permissions** tab is used to define permissions for the selected report.

Permissions determine which users or groups can use the report. A detailed description of the permissions mechanism is available in the [**Permissions**](/i18n/en/docusaurus-plugin-content-docs/version-7.7/spuma-admin/uprawnienia.md) section.
