# Allowed Values Tab

The **Allowed Values** tab is used to define the entries available in the static dictionary.

Each dictionary entry consists of a technical value and a description.

---

## Properties

- `Value` - Dictionary entry code.

:::warning
The code must be unique within the dictionary.
:::

- `Description` - Dictionary entry description displayed to the user.

> **Example:** *The `Departments` dictionary can contain the following values:*
>
> | Value | Description |
> | --- | --- |
> | `ADM` | Administration |
> | `MAG` | Warehouse |
> | `PROD` | Production |
> | `ZARZ` | Management |
