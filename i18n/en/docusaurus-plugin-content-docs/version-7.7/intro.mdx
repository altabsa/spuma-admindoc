## Introduction

The **SPUMA** system can be configured in two main ways, depending on the organization's needs and the adopted administration model:

1. **Using the SPUMA-ADMIN application** – this is the primary and recommended method of configuration, carried out through the application interface.
2. **Using SQL Server procedures and functions** *(optional)* – this method is intended for more advanced scenarios, such as automating operations or integrating with other administration mechanisms.

Regardless of the selected method, the target system configuration is stored entirely in the **SQL** database in the dedicated **SPUMA** database.

---

## SPUMA_ADMIN Application

To start configuring the system using the **SPUMA_ADMIN** application, log in with a user account that has the **administrator** role assigned.

After a fresh installation of the system, the default user **admin** is available. This user has the required administrative permissions and can be used to perform the initial environment configuration.
