# Dictionaries Tab

The **Dictionaries** tab contains a list of system dictionaries assigned to the company.

From this tab, you can add, edit, and delete dictionaries assigned to the company.

---

## Properties

- `Name` - Dictionary code.

- `Description` - Dictionary description displayed in the administration application.

- `Pattern` - A string that triggers a dictionary suggestion.

- `Use as suggestion` - Enables the use of the dictionary as a source of suggestions.

  > In the previous version, this mechanism worked when editing document text fields. After entering the value defined in the `Pattern` field, e.g. `Projekt`, the system opened a list of values from the assigned dictionary and allowed a value to be selected for the field being edited.

A detailed description of how system dictionaries work is available in the [**System Dictionaries**](/i18n/en/docusaurus-plugin-content-docs/current/spuma-admin/Slowniki/Slowniki-systemowe/systemowe.md) section.
