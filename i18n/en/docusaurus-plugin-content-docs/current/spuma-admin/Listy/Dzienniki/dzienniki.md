# Correspondence Logs

**Correspondence Logs** are used to register events and record entries in SPUMA.

A correspondence log entry can represent, among other things:

- sending a shipment,
- receiving a letter,
- receiving an e-mail message,
- creating an advice.

When creating a correspondence log, select its type:

- **Normal** - standard correspondence log configured manually,
- **Advice** - correspondence log intended for registering advices. When it is created, the system automatically adds the required configuration and SQL parameters.

---

## Correspondence Log Configuration

Correspondence log configuration defines the entry structure, the way data is retrieved and presented, and permissions.

The configuration is divided into the following tabs:

- [**General**](./ogolne),
- [**SQL Parameters**](./parametrySQL),
- [**Column Format**](./format-kolumn),
- [**Attributes**](./atrybuty),
