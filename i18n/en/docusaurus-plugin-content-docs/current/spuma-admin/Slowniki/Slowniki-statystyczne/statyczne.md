# Static Dictionaries

**Static Dictionaries** contain fixed sets of values defined directly in the administration application.

From the list, you can:

- add a new dictionary,
- delete the selected dictionary,
- select a dictionary for editing.

---

## Static Dictionary Configuration

Static dictionary configuration is divided into the following tabs:

- [**General**](./ogolne),
- [**Allowed Values**](./dozwolone-wartosci),
- [**Classes**](./klasy).
