# User Dictionaries

A **User Dictionary** is defined directly in the configuration of a class attribute.

It works similarly to a static dictionary, but its values are stored locally for a specific attribute. The dictionary is not shared with other attributes and is not defined as a separate item in the **Dictionaries** section.

User dictionary configuration is available after selecting the `User Dictionary` type for the attribute.

## Properties

For each dictionary entry, define:

- `Value` — value stored in the attribute,
- `Description` — description displayed to the user.
