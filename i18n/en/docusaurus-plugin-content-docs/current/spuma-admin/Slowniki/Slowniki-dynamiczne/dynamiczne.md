# Interactive Dictionaries

**Interactive Dictionaries** retrieve values based on an SQL query defined directly in the dictionary configuration.

Data is retrieved when the dictionary is used, for example when opening the list of values. This ensures that the dictionary returns current data from the source, but requires an active database connection.

The query can use parameters that retrieve values from the parent object.

---

## Interactive Dictionary Configuration

Interactive dictionary configuration is divided into the following tabs:

- [**General**](./ogolne),
- [**Parameters**](./parametry),
- [**Classes**](./klasy).
