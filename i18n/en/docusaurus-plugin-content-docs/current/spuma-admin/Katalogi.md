# Directories

The **Directories** section is used to define the repository directory structure for the selected company.

The directory tree is built hierarchically.

A directory can be created as:

- **root directory** - created without specifying a parent directory,
- **subdirectory** - created within the selected parent directory.

When adding a root directory, use the add option available for the entire directory tree. When adding a subdirectory, use the add option available for the selected parent directory.

Directories are deleted from the directory tree.
