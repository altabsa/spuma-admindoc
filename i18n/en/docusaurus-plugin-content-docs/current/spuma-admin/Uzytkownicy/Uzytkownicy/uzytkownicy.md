# Users

The **Users** section is used to manage user accounts and their configuration.

From the list, you can:

- add a new user,
- delete the selected user,
- search for a user,
- select a user for editing.

---

## User Configuration

User configuration is divided into the following tabs:

- [**General**](./ogolne),
- [**Permissions**](./uprawnienia),
- [**Signature**](./podpis),
- [**EMail**](./email),
- [**EDoc Exchange**](./wymiana-edok),
- [**Substitution**](./zastepstwo),
- [**Groups**](./grupy).
