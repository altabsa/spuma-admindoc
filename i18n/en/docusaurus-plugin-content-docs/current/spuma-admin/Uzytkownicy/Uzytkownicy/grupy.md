# Groups Tab

The **Groups** tab contains a [list of groups](/i18n/en/docusaurus-plugin-content-docs/current/spuma-admin/Uzytkownicy/Grupy/grupy.md) to which the user is assigned.

The list is populated based on the user group configuration.

From the list, you can navigate directly to the configuration of the selected group.

:::note
User-to-group assignments are not defined directly in this tab.
:::
