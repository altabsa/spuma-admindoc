# EMail Tab

The **EMail** tab contains email notification settings and the user's IMAP mailbox configuration.

---

## Properties

- `Reply to` - Email address used for sending notifications and receiving replies.

:::warning
The email address must be unique across the entire database.
:::

- `Email template` - Text fragment appended to messages sent in notifications.

- `Event information` - Specifies the events for which the user receives email notifications.

- `Host` - IMAP server address.

- `IMAP Port` - IMAP server port.

- `IMAP UserID` - User name used to connect to the IMAP server.

- `IMAP Password` - IMAP user password.

- `IMAP SSL` - Enables SSL for communication with the IMAP server.

- `Folder (,)` - List of IMAP folders used to retrieve messages. Folder names must be separated by commas.
