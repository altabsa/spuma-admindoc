# User Profile

The **User Profile** menu contains basic operations related to the currently logged-in user.

Available options:

- **Help** - Opens the SPUMA documentation.
- **Check licenses** - Opens information about license usage.
- **Log out** - Ends the current user session.

## Check Licenses

The **Check licenses** window displays:

- the number of available licenses,
- the number of licenses currently in use,
- the list of sessions using licenses.

For each active session, information is available including the user, login date, and last activity.

Additional operations are available in the upper-right corner:

- **Refresh** - Reloads the current license usage status.
- **Download licenses** - Downloads purchased licenses from the licensing system. This function is used when licenses are activated for the first time and after increasing the number of purchased licenses.

:::note
Licenses are generated by the licensing system. After the initial download, there is no need to use **Download licenses** again unless the number of purchased licenses has been increased.
:::
