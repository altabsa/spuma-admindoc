# Service

The **Service** section contains technical tools for handling documents that require administrative intervention.

Available operations:

- **Restore from trash** - Restores a document marked as deleted.
- **To edit** - Moves the document to a state that allows it to be edited again.
- **Repair OCR** - Removes the document from the OCR process if the process did not complete correctly.
- **Delete** - Permanently deletes the document from SPUMA.

:::warning
The **Delete** operation permanently removes the document from the system.
:::
