# Database

This section contains the technical description of the SPUMA database.

The documentation includes:

- [**Tables**](/i18n/en/docusaurus-plugin-content-docs/current/database/Tables/index.md),
- [**Procedures**](/i18n/en/docusaurus-plugin-content-docs/current/database/Procedures/index.md),
- [**Functions**](/i18n/en/docusaurus-plugin-content-docs/current/database/Functions/index.md).

Each area is described in a separate section.

Some advanced SPUMA features are configured using SQL procedures and functions.

:::warning
- Modifications to procedures and functions should be performed by technical personnel familiar with SQL and the SPUMA database structure.
- Direct modification of database data using `INSERT`, `UPDATE`, and `DELETE` statements is prohibited.
- When editing procedures and functions, it is recommended to add comments describing changes made in relation to the standard functionality.
:::
