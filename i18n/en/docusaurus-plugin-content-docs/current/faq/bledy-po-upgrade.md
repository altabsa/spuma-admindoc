# Error Messages After Upgrade

**Reported problem**

After upgrading SPUMA, various error messages may appear in the web application, for example:

```text
Ae.fill is not a function
```

---

**Solution**

The problem may be related to data stored in the browser from a previous version of the application.

First, check SPUMA in incognito mode.

If the problem does not occur in incognito mode:

1. clear the browser history,
2. remove cached data,
3. restart the browser,
4. open the SPUMA web application again.

If the problem still occurs, report the issue to the administrator together with the displayed error message.
