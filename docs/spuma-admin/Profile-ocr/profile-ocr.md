# Profile OCR

Sekcja **Profile OCR** zawiera konfigurację profili wykorzystywanych podczas rozpoznawania dokumentów.

Profil OCR definiuje parametry przekazywane do mechanizmu OCR oraz sposób obsługi dokumentów przetwarzanych z użyciem danego profilu.

Konfiguracja profilu jest podzielona na zakładki:

- [**Ogólne**](./ogolne)
