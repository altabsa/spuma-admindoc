# Serwis

Sekcja **Serwis** zawiera narzędzia techniczne do obsługi dokumentów wymagających interwencji administracyjnej.

Dostępne operacje:

- **Przywrócić z kosza** - Przywraca dokument oznaczony jako skasowany.
- **Do edycji** - Przenosi dokument do stanu umożliwiającego ponowną edycję.
- **Napraw OCR** - Wycofuje dokument z procesu OCR w przypadku jego nieprawidłowego zakończenia.
- **Usuń** - Trwale usuwa dokument z SPUMA.

:::warning
Operacja **Usuń** powoduje trwałe usunięcie dokumentu z systemu.
:::
