# Katalogi

Sekcja **Katalogi** służy do definiowania struktury katalogów repozytorium dla wybranej firmy.

Drzewo katalogów jest budowane hierarchicznie.

Katalog może zostać utworzony jako:

- **katalog główny** - tworzony bez wskazania katalogu nadrzędnego,
- **podkatalog** - tworzony w ramach wskazanego katalogu nadrzędnego.

Przy dodawaniu katalogu głównego używana jest opcja dodawania dostępna dla całego drzewa katalogów. Przy dodawaniu podkatalogu używana jest opcja dodawania dostępna przy wybranym katalogu nadrzędnym.

Usunięcie katalogu odbywa się z poziomu drzewa katalogów.
