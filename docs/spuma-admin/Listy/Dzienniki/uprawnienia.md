# Zakładka - Uprawnienia

Zakładka **Uprawnienia** służy do definiowania uprawnień dla wpisów danego dziennika.

Uprawnienia zdefiniowane na dzienniku są stosowane do wszystkich jego wpisów. Szczegółowy opis mechanizmu uprawnień znajduje się w sekcji [**Uprawnienia**](/docs/spuma-admin/uprawnienia.md).
