# Dzienniki

**Dzienniki** służą do rejestrowania zdarzeń i wpisów ewidencyjnych w SPUMA.

Wpis dziennika może reprezentować m.in.:

- wysłanie przesyłki,
- otrzymanie pisma,
- odebranie wiadomości e-mail,
- utworzenie awizacji.

Podczas tworzenia dziennika wybierany jest jego typ:

- **Normalny** - standardowy dziennik konfigurowany ręcznie,
- **Awiza** - dziennik przeznaczony do rejestrowania awizacji. Przy jego utworzeniu system automatycznie dodaje wymaganą konfigurację i parametry SQL.
