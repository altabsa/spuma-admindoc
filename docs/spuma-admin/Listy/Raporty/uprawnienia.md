# Zakładka - Uprawnienia

Zakładka **Uprawnienia** służy do definiowania uprawnień dla danego raportu.

Uprawnienia określają, którzy użytkownicy lub grupy mogą korzystać z raportu. Szczegółowy opis mechanizmu uprawnień znajduje się w sekcji [**Uprawnienia**](/docs/spuma-admin/uprawnienia.md).
