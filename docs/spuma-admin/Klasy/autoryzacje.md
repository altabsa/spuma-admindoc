# Zakładka - Autoryzacje

Zakładka **Autoryzacje** zawiera ustawienia [schematów](/docs/spuma-admin/Autoryzacje/Schematy/schematy.md)/[procesów](/docs/spuma-admin/Autoryzacje/Procesy/procesy.md) autoryzacji dostępnych dla dokumentów danej klasy.

---

## Właściwości

- `Własny schemat` - Zezwala użytkownikowi na utworzenie własnego schematu autoryzacji i przekazanie dokumentu do obiegu.

- `Schemat jest wymagany` - Określa, czy dokument musi zostać przypisany do schematu autoryzacji.

- `Schemat domyślny` - Określa schemat autoryzacji przypisywany domyślnie do dokumentów tej klasy.

- `Dostępne schematy` - Zawiera listę schematów/procesów autoryzacji dostępnych dla klasy.
