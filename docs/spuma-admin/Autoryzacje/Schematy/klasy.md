# Zakładka - Klasy

Zakładka **Klasy** zawiera listę klas, do których przypisany jest dany schemat autoryzacji.

Lista jest uzupełniana automatycznie na podstawie konfiguracji klas.

Z poziomu listy możesz przejść bezpośrednio do konfiguracji wybranej klasy.

:::note
Lista ma charakter informacyjny. Powiązanie schematu z klasą jest definiowane w konfiguracji klasy.
:::
