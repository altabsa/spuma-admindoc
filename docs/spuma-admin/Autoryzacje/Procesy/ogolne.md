# Zakładka - Ogólne

Zakładka **Ogólne** zawiera podstawowe informacje o procesie autoryzacji.

---

## Właściwości

- `Nazwa` - Nazwa procesu.

:::warning
Nazwa procesu powinna być unikalna w bazie danych.
:::

- `Opis` - Opis procesu widoczny w konfiguracji administratora.
