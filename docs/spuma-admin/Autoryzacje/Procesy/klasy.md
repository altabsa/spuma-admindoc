# Zakładka - Klasy

Zakładka **Klasy** zawiera listę klas, do których przypisany jest dany proces autoryzacji.

Lista jest uzupełniana automatycznie na podstawie konfiguracji klas.

Z poziomu listy możesz przejść bezpośrednio do konfiguracji wybranej klasy.

:::note
Lista ma charakter informacyjny. Powiązanie procesu z klasą jest definiowane w konfiguracji klasy.
:::
