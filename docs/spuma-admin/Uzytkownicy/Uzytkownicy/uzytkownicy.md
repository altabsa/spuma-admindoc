# Użytkownicy

Sekcja **Użytkownicy** służy do zarządzania kontami użytkowników oraz ich konfiguracją.

Z poziomu listy możesz:

- dodać nowego użytkownika,
- usunąć wybranego użytkownika,
- wyszukać użytkownika,
- wybrać użytkownika do edycji.

---

## Konfiguracja użytkownika

Konfiguracja użytkownika jest podzielona na zakładki:

- [**Ogólne**](./ogolne),
- [**Uprawnienia**](./uprawnienia),
- [**Podpis**](./podpis),
- [**EMail**](./email),
- [**Wymiana EDok.**](./wymiana-edok),
- [**Zastępstwo**](./zastepstwo),
- [**Grupy**](./grupy).
