# Słowniki statyczne

**Słowniki statyczne** zawierają stałe zestawy wartości definiowane bezpośrednio w panelu administracyjnym.

Z poziomu listy możesz:

- dodać nowy słownik,
- usunąć wybrany słownik,
- wybrać słownik do edycji.
