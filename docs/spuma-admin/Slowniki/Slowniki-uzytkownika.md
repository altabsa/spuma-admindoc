# Słowniki użytkownika

**Słownik użytkownika** jest definiowany bezpośrednio w konfiguracji atrybutu klasy.

Działa podobnie do słownika statycznego, ale jego wartości są przechowywane lokalnie dla konkretnego atrybutu. Słownik nie jest współdzielony z innymi atrybutami ani definiowany jako osobny element w sekcji **Słowniki**.

Konfiguracja słownika użytkownika jest dostępna po wybraniu typu `Słownik użytkownika` dla atrybutu.

## Właściwości

Dla każdej pozycji słownika definiowane są:

- `Wartość` - wartość zapisywana w atrybucie,
- `Opis` - opis wyświetlany użytkownikowi.
