# Zakładka - Klasy

Zakładka **Klasy** zawiera listę klas obsługiwanych przez daną firmę.

Z poziomu zakładki możesz dodawać i usuwać klasy przypisane do firmy.

---

## Wybrane klasy

Sekcja **Wybrane klasy** zawiera klasy dostępne dla dokumentów rejestrowanych w ramach firmy.
