# Zakładka - Integracja SAP

Zakładka **Integracja SAP** zawiera ustawienia połączenia firmy z SAP oraz parametry wykorzystywane podczas wymiany danych.

---

## Właściwości

- `Adres SL` - Adres SAP Service Layer.

- `Użytkownik` - Użytkownik SAP używany do połączenia.

- `Hasło` - Hasło użytkownika SAP.

- `Generowanie nowego kodu PH (SQL SL)` - Zapytanie SQL wykonywane przez Service Layer w celu wygenerowania nowego kodu partnera handlowego.

- `Domyślny indeks` - Kod domyślnego indeksu SAP.

- `ID oddziału` - Identyfikator oddziału używany w SAP.

- `Pole daty sprzedaży` - Nazwa technicznego pola SAP używanego do zapisania daty sprzedaży.

- `Pole numeru e.dokumentu` - Nazwa technicznego pola SAP używanego do zapisania numeru dokumentu elektronicznego.
