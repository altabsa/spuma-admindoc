# Instrukcja wstępnej konfiguracji systemu SPUMA

## Cel dokumentu

Celem instrukcji jest przeprowadzenie podstawowej konfiguracji systemu SPUMA po zakończeniu instalacji i potwierdzeniu poprawnego działania środowiska.

Wstępna konfiguracja obejmuje:

- pozyskanie i aktywację licencji,
- konfigurację główną systemu,
- konfigurację firm,
- definiowanie użytkowników i grup,
- konfigurację obiegów dokumentów,
- nadawanie uprawnień,
- konfigurację integracji z systemami zewnętrznymi.

Poszczególne kroki należy wykonywać w kolejności wynikającej z zależności pomiędzy konfigurowanymi elementami.
