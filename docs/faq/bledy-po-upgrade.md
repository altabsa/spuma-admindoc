# Komunikaty błędów po aktualizacji

**Zgłoszony problem**

Po aktualizacji SPUMA w aplikacji WWW mogą pojawiać się różne komunikaty błędów, np.:

```text
Ae.fill is not a function
```

---

**Rozwiązanie**

Problem może być związany z danymi zapisanymi w przeglądarce po wcześniejszej wersji aplikacji.

W pierwszej kolejności sprawdź działanie SPUMA w trybie incognito.

Jeżeli w trybie incognito problem nie występuje:

1. wyczyść historię przeglądarki,
2. usuń dane zapisane w pamięci podręcznej,
3. uruchom ponownie przeglądarkę,
4. ponownie otwórz aplikację WWW SPUMA.

Jeżeli problem nadal występuje, zgłoś błąd administratorowi wraz z treścią wyświetlanego komunikatu.
